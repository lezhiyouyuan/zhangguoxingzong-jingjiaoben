# 引言

星学复兴，始于正本；古法重明，必先正籍。

《张果星宗》，又称《果老星宗》《星宗命格》《张果星宗命格大全》，为华夏星学经典书籍，唐代张果撰，今传本由明代陆位辑校。

今据 [涛君谈星](https://mp.weixin.qq.com/s/1uoVZ1hyhPvpwIegHW1RxQ) 文本，参考古籍，精校厘定，重为排印，辑成《张果星宗：精校本》。

古籍版本：明万历廿一年（1593年）版《新編評註通⽞先⽣張果星宗⼤全》，日本平⼭⽂库 MA/591 00070308538。原有眉批及说明等予以保留。

特集《太平广记·张果》《历世真仙体道通鉴·张果》《太平广记钞·张果》于前，以飨读者。

鲁鱼未辨，敬祈指正：lezhiyouyuan@gmail.com 。
